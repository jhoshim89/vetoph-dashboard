# vetoph-dashboard
수의안과 프로젝트 대시보드 (비공개 용도 — URL 비밀 유지). 숫자 통계만 포함.

## 운영 원칙

- 이 저장소가 수의안과 대시보드의 기준 입구다.
- 통합 산출물 허브에는 올리지 않는다.
- 보고 싶은 항목만 홈에 카드로 둔다.
- 최신 수집·처리 현황과 코퍼스 내용은 `overview.html` 하나로 합친다.
- 오래된 전체 분석은 `detail.html`에 아카이브로 둔다.
- 매일 헷갈리지 않도록 `http://127.0.0.1:8888/`도 이 저장소를 직접 서빙한다.
- 로컬 서버는 `python3 serve.py 8888`로 띄운다.
