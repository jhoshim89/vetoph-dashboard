수의안과 8,159편의 출판 연도

신경과학·시각 기초 paper를 빼고 본인 임상 영역만. 1960년대부터 본격 시작, 2010년대 정점(약 1,778편), 최근 6년(2020~2026)에 이미 1,611편 — 분야가 활발한 신호. 2000년대 Veterinary Ophthalmology 전문지 창간이 큰 분기점.

저널 분포 상위 20

두 줄의 "Veterinary Ophthalmology"는 대소문자만 다른 같은 저널 — 통계상 두 묶음으로 흩어져 있음(아래 이슈 섹션 참조). 신경과학·시각 기초 저널(Brain research, Vision research 등)도 상당히 들어있음 — 시각계 학제간 특성.

수의안과 확정 8,159편의 저널 (Top 10)

전체 8천 편의 저널 분포. Veterinary Ophthalmology 한 저널이 약 1,700편(대소문자 합산)으로 압도. JAVMA·AJVR·Veterinary record 같은 일반 수의학지가 보조 축.

2. NAS에 받아둔 본문 파일

manifest(원본 파일 목록)와 디스크 실제 파일. PDF가 9할 차지.

파일 형식 분포

PDF · 출판사 XML · HTML

PDF 디렉토리 분포

오픈 액세스 비중이 절반에 가까움.

식별 키 분포

DOI 키 9할, PMID 키 1할.

출처(source) 분포 상위 15

sci-hub·elsevier 양대 경로가 절반 차지. 오픈 액세스(europepmc·crossref·openalex) + 학교 IP institutional 경로(inst, inst_html_pdf)가 나머지를 메움. 출처는 모두 35종.

파일 사이즈 요약

전체 약 16 GB. 보통 1편이 0.7 MB 안팎.
총 용량  약 15.83 GB
한 편 보통  676 KB (중앙값)
하위 10%  95 KB 미만 (짧은 letter/abstract만)
상위 10%  3.2 MB 초과 (그림 많은 본격 논문)
가장 큰 파일  76 MB (예외)
디스크 vs 목록  PDF는 사실상 일치(1편 결손). XML은 목록 1,257 vs 디스크 727편 — 절반은 출판사가 등록만 했고 받지 못함.

3. 본문 추출 결과

PDF·XML로부터 텍스트를 뽑은 결과. 본문 추출 자체는 사실상 100%.

추출 도구 분포

Grobid 9할, Apple Vision OCR이 보조, JATS는 출판사 XML 직파싱.

본문 추출 성공 여부

실패 27편은 사실상 0.1% 미만.

섹션 풍부함

4섹션 이상(Intro/Methods/Results/Discussion 다 잡힘)이 절반 이상.

한 논문의 본문 길이 분포

중앙값 약 1만 8천 자. 짧은 letter는 2천 자대, 본격 review는 4만 자 이상. 한국어로 환산하면 보통 paper 1편이 책 한 챕터 수준.

PDF 처리 상태

14,162편 중 95%는 안정적으로 끝남. 나머지 5%는 보류 — Grobid 재시도 줄, OCR 재시도, 아직 손 안 댄 것.

5. 발견된 이슈 두 가지

측정하면서 드러난, 정리하면 좋을 두 가지.

① 저널명 대소문자 중복

"Veterinary ophthalmology"와 "Veterinary Ophthalmology"가 서로 다른 저널로 박혀 있음. 두 묶음 합치면 약 1,700편 — 동일 저널.
영향: 저널 단위 통계·필터링에서 이 저널이 두 갈래로 흩어져 잡힘. 본인이 "Vet Ophth에서 N편 검색됐다" 같은 질문할 때 숫자가 절반만 나올 위험.

② 수의안과 숫자 두 갈래

Supabase 라이브 DB는 8,159편, 분류 결과 스냅샷 파일(5월 28일)은 8,631편. 약 470편 차이.
가능성: 분류 작업 이후 일부 paper가 Supabase에 반영되지 않았거나, 라벨이 살짝 갱신됐을 수 있음. 어느 쪽을 진실의 원천으로 둘지 한 번 맞춰두면 다음 RAG 적재할 때 혼동 없음.
